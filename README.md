The AI Store Manager helps manage:

- Shopify products

- Store design

1. Product Title
2. Short Description
3. Full Description
4. Key Features
5. Benefits
6. How to Use
7. Ingredients
8. Specifications
9. Product Category
10. Product Type
11. Collection
12. SEO Title
13. SEO Meta Description
14. Product Tags

## CJ Dropshipping Workflow

CJ Product
→ Product Analysis
→ AI Content Generation
→ Category Selection
→ Collection Selection
→ SEO
→ Price Recommendation
→ Shopify Draft
→ Owner Approval
→ Publish

## Safety

- Never store passwords in the code.
- Never expose API secrets.
- Use secure environment variables.
- Automatic publishing is disabled by default.
- Owner approval is required before publishing.
- Never invent product information.
- Never make unsupported medical claims.
